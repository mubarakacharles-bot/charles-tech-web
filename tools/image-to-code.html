Picture → code

For the Attendance & Stock picture, which is written inside the website code so it can never get lost. Works offline — your picture never leaves this computer.

  1. Choose your picture below (landscape 16:9 is best, e.g. 900×507).
  2. Press Copy.
  3. Open index.html in a text editor (Notepad, VS Code…), search for ATTENDANCE PICTURE.
  4. On the line :root{--ban:url(data:image/…) replace everything between url( and ) with what you copied. Save.
